P: A klasa?
K: Prvi oktet 0–127 = 0-127 | 0 do 127 | 1-126 | 1 do 126
K: Počinje bitom 0 = bitom 0 | bit 0 | bitu 0 | sa 0 | nulom | 0 bit
K: 1 oktet mreža, 3 okteta host = tri okteta | 3 okteta | prvi oktet | 1 oktet | jedan oktet
K: 126 mreža = 126
K: 2^24 – 2 hosta = 2^24 | 2 na 24 | 16777214 | 16.777.214
K: Maska 255.0.0.0 = 255.0.0.0
PRAG: 3
O: Klasa A IP adresa obuhvata adrese kod kojih je prvi oktet u rasponu 0–127 i u binarnom zapisu uvijek počinje bitom 0.
O: Kod ove klase prvi oktet predstavlja mrežni dio, dok preostala tri okteta čine host dio, što omogućava veliki broj uređaja u jednoj mreži.
O: Postoji ukupno 126 mreža klase A, a svaka mreža ima 2^24 – 2 iskoristive IP adrese, pri čemu se ne računaju adresa mreže i broadcast adresa.
O: Defaultna subnet maska klase A je 255.0.0.0.

P: B klasa?

K: Počinje bitovima 10 = bitovima 10 | bitovi 10 | bitima 10 | sa 10 | 10 bit

P: Specijalne IP adrese? Navesti i opisati!
K: Loopback = loopback | loop back | petlj
K: 127.0.0.1 (opseg 127.x.x.x) = 127
K: Testiranje / komunikacija sa samim sobom = samim sobom | sam sa sobom | sa sobom | testir
K: 0.0.0.0 – defaultna ruta = 0.0.0.0 | default | podrazumijevan
K: Link-local adrese = link-local | link local | linklocal | apipa
K: Opseg 169.254.x.x = 169.254
PRAG: 3
O: Loopback adresa je specijalna IP adresa koju računar koristi za komunikaciju sa samim sobom radi testiranja mrežne funkcionalnosti, pri čemu se koristi adresni opseg 127.0.0.0 – 127.255.255.255, a najčešće 127.0.0.1.
O: Adresa 0.0.0.0 predstavlja defaultnu rutu i koristi se kada računar ili router nema precizno definisanu rutu ka odredišnoj mreži, pa se sav nepoznati saobraćaj usmjerava ovom rutom.
O: Link-local adrese se automatski dodjeljuju od strane operativnog sistema kada IP konfiguracija nije dostupna, kako bi se omogućila osnovna mrežna komunikacija, a koriste opseg 169.254.0.0 – 169.254.255.255.

P: Privatne IP adrese?

K: Nisu dostupne sa Interneta / sigurnost = nisu dostupn | nisu direktno | nedostupn | sigurn | javn
K: NAT / PAT = nat | pat
K: Klasa A: 10.0.0.0/8 = 10.0.0.0 | 10/8
K: Klasa B: 172.16.0.0/12 = 172.16 | 172
K: Klasa C: 192.168.0.0/16 = 192.168
PRAG: 3
O: Privatne IP adrese koriste se unutar lokalnih mreža i nisu direktno dostupne sa Interneta, čime se povećava sigurnost i smanjuje potreba za velikim brojem javnih IP adresa.
O: Računari koji koriste privatne IP adrese mogu pristupati Internetu pomoću NAT ili PAT mehanizama, koji omogućavaju prevođenje privatnih adresa u javnu IP adresu.
O: Privatni adresni opsezi su unaprijed definisani i obuhvataju klasu A (10.0.0.0/8), klasu B (172.16.0.0/12) i klasu C (192.168.0.0/16).

P: 3-way handshake?
K: TCP = tcp
K: Uspostava pouzdane konekcije = uspostav | konekcij | veza | vezu | veze | pouzdan
K: Klijent šalje SYN = syn
K: Server odgovara SYN-ACK = syn-ack | synack | syn ack | syn i ack
K: Završni ACK = ack
K: Sekvencijalni broj = sekvenc | redni broj | seq
PRAG: 4
O: 3-way handshake je postupak kojim TCP protokol uspostavlja pouzdanu konekciju prije razmjene podataka, kako bi se sinhronizovali učesnici u komunikaciji.
O: Proces započinje tako što klijent šalje SYN segment zajedno sa početnim sekvencijalnim brojem, čime zahtijeva uspostavu konekcije i omogućava praćenje redoslijeda segmenata.
O: Server odgovara SYN-ACK segmentom, kojim potvrđuje prijem klijentovog zahtjeva, šalje sopstveni sekvencijalni broj i definiše naredni očekivani segment.
O: Konekcija se uspostavlja kada klijent pošalje završni ACK, nakon čega je veza aktivna i može započeti razmjena podatkovnih segmenata.
O: Na sličan princip kao uspostava, TCP konekcija se i prekida, kroz razmjenu kontrolnih poruka između učesnika.

P: DNS?

K: Prevodi ime domene u IP adresu = prevo | preved | pretvar | mapir | razrjes | razrijes
K: IP adresa = ip
K: Ljudima je lakše pamtiti imena = pamt | zapamt | ljud | covjek | korisni
K: DNS server = server
PRAG: 3
O: DNS (Domain Name System) je servis koji omogućava prevođenje logičkog imena domene u IP adresu, što je neophodno za mrežnu komunikaciju.
O: Iako računari komuniciraju isključivo putem IP adresa, ljudima je teško pamtiti numeričke vrijednosti, zbog čega se umjesto njih koriste nazivi domena.
O: Kada korisnik unese ime domene, DNS server ga prevodi u odgovarajuću IP adresu, a tek nakon toga se mrežni zahtjev realizuje koristeći IP adresu.

P: SLAAC (Stateless Address Autoconfiguration)?
K: Automatska konfiguracija IPv6 adresa = automatsk | autokonfig | auto konfig
K: Bez centralnog (DHCP) servera = bez server | bez dhcp | bez centraln | bez potrebe
K: Router Solicitation (RS) = solicitation | rs
K: Router Advertisement (RA) = advertisement | ra
K: Mrežni prefiks = prefiks | prefix
K: Interface ID = interface | eui
K: DAD (Duplicate Address Detection) = dad | duplicate | duplikat
K: Router ne vodi evidenciju (stateless) = evidencij | ne pamti | ne prati | ne cuva | stateless
PRAG: 4
O: SLAAC (Stateless Address Autoconfiguration) omogućava automatsku konfiguraciju IPv6 adresa na hostovima bez potrebe za centralnim serverom.
O: Host koristi Neighbor Discovery protokol (Router Solicitation poruku) da otkrije dostupne metode konfiguracije, a router odgovara Router Advertisement porukom koja sadrži mrežni prefiks i upute za generisanje Interface ID-a.
O: Nakon generisanja Interface ID dijela, host koristi DAD (Duplicate Address Detection) kako bi provjerio da li je njegova adresa jedinstvena u mreži.
O: Metoda se naziva stateless jer router ne vodi evidenciju o adresama koje je dodijelio hostovima, već samo šalje potrebne informacije za konfiguraciju.
---

P: Stateless DHCP konfigurisanje Ipv6 adresa (SLAAC + DHCP)?
K: Router šalje RA (Router Advertisement) = advertisement | ra
K: Prefiks, dužina prefiksa, default gateway = prefiks | prefix | gateway
K: Dodatni parametri (DNS) od DHCP servera = dns | dodatn | dhcp server
K: Link-local adresa = link-local | link local | linklocal
K: Interface ID: random ili EUI-64 = eui | random | nasumi | slucajn
K: DAD provjera jedinstvenosti = dad | duplicate | jedinstven
K: ICMPv6 poruke (133 RS, 134 RA, 135/136) = icmp | 133 | 134 | 135 | 136
K: Router Solicitation (RS) = solicitation | rs
PRAG: 4
O: Stateless DHCP za IPv6 kombinuje informacije od routera i DHCP servera, gdje router šalje RA (Router Advertisement) poruke sa mrežnim prefiksom, dužinom prefiksa i default gateway adresom, ali host dodatne parametre (npr. DNS) preuzima od DHCP servera.
O: Host prvo generiše link-local adresu koristeći random ili EUI-64 metod za Interface ID, a zatim provjerava jedinstvenost adrese u mreži pomoću DAD (Duplicate Address Detection) protokola kroz ICMPv6 poruke (tip 135/136).
O: Kada se adresa potvrdi kao jedinstvena, host je primjenjuje na interfejs i šalje Router Solicitation poruku (ICMP tip 133), na koju router odgovara RA porukom (ICMP tip 134).
O: Host koristi informacije iz RA poruke da odluči na koji način da se konfigurira, tj. koje adrese i dodatne parametre preuzima od DHCP servera, čime se završava stateless DHCP konfiguracija.
---

P: Statefull DHCP?
K: Host prima RA poruku = advertisement | ra
K: M bit postavljen na 1 = m bit | m bitom | m bita | bit m | m flag | m zastav | m=1 | m = 1
K: Sve informacije od DHCPv6 servera = dhcpv6 | dhcp v6 | dhcp server | sve konfig | sve inform
K: Server: poseban uređaj ili sam router = poseban | sam router | ili router | i router
K: Širi spektar opcija = siri | sire | sireg | sirok | vise opcij | vise konfig | spektar
K: Router može biti i DHCP klijent i server = klijent
PRAG: 3
O: Stateful DHCP za IPv6 se koristi kada host primi RA (Router Advertisement) poruku sa postavljenim M bitom na 1, što znači da će sve konfiguracione informacije dobiti od DHCPv6 servera.
O: DHCPv6 server može biti poseban uređaj u mreži ili sam router, a pruža širi spektar konfiguracionih opcija u odnosu na stateless metode.
O: Važno je napomenuti da u nekim scenarijima router može istovremeno funkcionisati i kao DHCP klijent i kao DHCP server, zavisno od potrebe mreže.
---

P: Tunneling (tuneliranje)?
K: IPv6 preko IPv4 mreže = ipv6 | ipv4
K: IPv6 paket unutar IPv4 paketa = unutar | enkapsul | stavlja
K: Dual-stack router = dual
K: Izvlači se na odredištu = izvlac | izvadi | odredisn
K: Povećana latencija = latenc | kasnjenj
PRAG: 3
O: Tuneliranje omogućava prenos IPv6 paketa preko IPv4 mreže tako što se IPv6 paket stavi unutar IPv4 paketa i pošalje do drugog dual-stack routera.
O: Na odredišnom routeru IPv6 paket se izvlači iz IPv4 paketa i dalje se prosljeđuje u izvornom obliku.
O: Omogućava kompatibilnost, ali povećava latenciju zbog dodatnog enkapsuliranja.
---

P: Kako radi NAT (Network Address Translation)?
K: Privatne u javne adrese = privatn | javn
K: Pristup Internetu = internet

K: Izgleda kao da NAT uređaj inicira = inicir | kao da
K: Odgovor nazad originalnom hostu = nazad | original | odgovor
PRAG: 3
O: NAT prevodi privatne IP adrese u javne, omogućavajući uređajima u lokalnoj mreži pristup Internetu.

O: Zahtjev hosta prosljeđuje preko javnog interfejsa kao da ga sam inicira, a odgovore preusmjerava nazad originalnom hostu.
